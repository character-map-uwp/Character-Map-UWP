# Character Map UWP

A modern, native UWP replacement for the Win32 Character Map and Windows Font Viewer with flawless high DPI and touch support.

> **WPF migration:** active development now targets WPF on .NET 10. Open
> `CharacterMap/CharacterMap.Wpf.slnx`. The original UWP application is retained
> as the feature-parity reference. See
> [`CharacterMap/MIGRATION-WPF.md`](CharacterMap/MIGRATION-WPF.md) for status and
> architecture notes.
